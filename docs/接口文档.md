# 喷雾干燥工艺模型服务 · 接口文档

> 服务代码：`app.py` + `services/`
> 文档依据：代码实现逐字段核对（非设计稿），与 `app.py`、`services/common.py` 保持一致
> 最后更新：2026-11-17

## 1. 基本信息

| 项目 | 值 |
| --- | --- |
| 服务地址 | `http://<host>:5008` |
| 监听 | `0.0.0.0:5008` |
| 协议 | HTTP / JSON |
| 字符集 | UTF-8 |
| 鉴权 | 无（内网部署） |
| 启动 | `python app.py`，或容器内 `./start.sh`（进程退出后 3 秒自动拉起） |

### 1.1 统一响应结构

所有接口返回统一外层结构：

```json
{
  "code": 0,
  "message": "success",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | int | `0` = 成功；`-1` = 失败；**`/optsearch` 成功时为 `200`**（历史遗留，前端需单独判断） |
| `message` | string | 成功固定为 `"success"`；失败为错误描述 |
| `data` | object \| null | 成功时为业务数据，失败时为 `null` |

### 1.2 错误响应

```json
{ "code": -1, "message": "missing model_id", "data": null }
```

常见错误信息：

| message | 触发条件 |
| --- | --- |
| `request body must be JSON` | 请求体不是合法 JSON |
| `missing model_id` | `/predict` 未传 `model_id` |
| `missing features` | `/predict` 特征为空 |
| `missing params (list of parameter configs)` | `/optsearch` 未传 `params` |
| `no trained model, please call /train first` | `/optsearch` 无可用模型 |
| `model dir not found: ...` | `model_id` 对应目录不存在 |
| `dataset_id=N has no rows in ...` | 数据库无对应数据集 |
| `cannot connect to MySQL ...` | 数据库连接失败 |
| `unknown algorithm: xxx (weighted / mopso)` | 算法名非法 |
| `alpha (particle weight) must be in [0,1]` | `alpha` 越界 |

## 2. 参数字典

模型特征 10 个（DCS 7 个 + 物料/设备 3 个），顺序即 SVR 输入顺序。

### 2.1 模型特征（参与训练与预测）

| 英文 key | 中文含义 | 单位 | 类型 | 说明 |
| --- | --- | --- | --- | --- |
| `sic3203` | 喷雾风机变频 | Hz | float | DCS 点位 SIC3203 |
| `sic1014` | 细粉风机变频 | Hz | float | DCS 点位 SIC1014 |
| `sic3204` | 回用风机变频 | Hz | float | DCS 点位 SIC3204 |
| `prc3101` | 喷雾压力 | MPa | float | DCS 点位 PRC3101 |
| `fi3108` | 喷雾流量 | m³/h | float | DCS 点位 FI3108 |
| `sic1008` | 细粉分级器变频 1 | Hz | float | DCS 点位 SIC1008 |
| `sic1009` | 细粉分级器变频 2 | Hz | float | DCS 点位 SIC1009 |
| `solid_content` | 胶体固含量 | — | float | 物料参数 |
| `gun_count` | 喷枪数量 | 个 | int | 离散值，寻优时自动取整 |
| `viscosity` | 黏度 | — | float | 物料参数 |

### 2.2 展示参数（不参与模型）

可在请求中携带，服务端**自动忽略**，仅在寻优结果中原样回显。

| 英文 key | 中文含义 | 单位 |
| --- | --- | --- |
| `nozzle_31_count` | 喷嘴 3.1 口径数量 | 个 |
| `nozzle_33_count` | 喷嘴 3.3 口径数量 | 个 |

### 2.3 目标变量（出参）

| 英文 key | 中文含义 | 单位 | 备注 |
| --- | --- | --- | --- |
| `particle_size_um` | 粒径 D(V,0.5) | μm | 预测接口字段名 |
| `energy_consumption` | 能源消耗 | — | 预测接口字段名 |
| `psd_0_20` | 粒度分布 0~20μm | % | 体积分数 |
| `psd_0_40` | 粒度分布 0~40μm | % | 体积分数 |
| `psd_0_80` | 粒度分布 0~80μm | % | 体积分数 |
| `psd_0_105` | 粒度分布 0~105μm | % | 体积分数 |
| `psd_0_149` | 粒度分布 0~149μm | % | 体积分数 |

> 训练/相关性接口中，目标列 key 为 `particle_size`（不带 `_um`），预测接口出参为 `particle_size_um`，两者不可混用。

## 3. 数据源规则

`/train`、`/correlation` 的数据来自 MySQL 表 `fcc_dataset_row`，**不再读取本地文件**。

`dataset_id` 解析优先级：

1. 请求体中的 `dataset_id`
   - `> 0`：只取该数据集的行
   - **`= 0`：不按数据集过滤，取整表全部行**
2. 环境变量 `DEFAULT_DATASET_ID`
3. 表中最大的 `dataset_id`

请求体中的 `data_path` 字段**已废弃**，传了也会被忽略。

环境变量（覆盖默认值）：

| 变量 | 默认值 |
| --- | --- |
| `DB_HOST` | `127.0.0.1` |
| `DB_PORT` | `3307` |
| `DB_USER` | `zsh` |
| `DB_PASSWORD` | `Zsh1234@` |
| `DB_NAME` | `zsh_fcc` |
| `DB_DATASET_TABLE` | `fcc_dataset_row` |
| `DEFAULT_DATASET_ID` | 空（回退到最大 dataset_id） |

## 4. 接口详情

### 4.1 `POST /predict` — 预测粒径 / 能耗 / 粒度分布

按 `model_id` 加载训练产物，输入 10 个模型特征，输出多目标预测值。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `model_id` | string | 是 | 训练返回的模型 ID（14 位时间戳） |
| `features` | object | 是 | `{英文key: 数值}`，需包含全部 10 个模型特征 |

支持两种写法：封装在 `features` 中，或平铺在 body 里（除 `model_id` 外的键）。

```json
{
  "model_id": "20261113154943",
  "features": {
    "sic3203": 47.12,
    "sic1014": 45.38,
    "sic3204": 49.15,
    "prc3101": 10.48,
    "fi3108": 9.02,
    "sic1008": 12.61,
    "sic1009": 12.36,
    "solid_content": 38.8,
    "gun_count": 8,
    "viscosity": 20,
    "nozzle_31_count": 6,
    "nozzle_33_count": 2
  }
}
```

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "model_id": "20261113154943",
    "particle_size_um": 74.8631,
    "energy_consumption": 134.4848,
    "psd_0_20": 1.11,
    "psd_0_40": 12.9284,
    "psd_0_80": 54.9533,
    "psd_0_105": 74.0771,
    "psd_0_149": 91.664
  }
}
```

> 旧模型若未训练粒度分布，`psd_*` 字段会省略，不报错。
> 缺任一模型特征会报 `missing model feature: '<key>'`。

### 4.2 `POST /train` — 训练模型

从数据库取数，训练 7 个独立 SVR（粒径、能耗、5 档粒度分布），产物保存到 `weight/<model_id>/`。

**请求体**（全部可选，`{}` 即训练最新数据集）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `dataset_id` | int | 否 | `0` = 整表；不传 = 环境变量或最大 `dataset_id` |

```json
{ "dataset_id": 1 }
```

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "model_id": "20261117143000",
    "train_samples": 204,
    "test_samples": 51,
    "particle_size":        { "mse": 4.9932, "mape": 2.4017, "1_mape": 0.976,  "r2": 0.1523 },
    "energy_consumption":   { "mse": 169.6318, "mape": 6.3778, "1_mape": 0.9362, "r2": -0.0272 },
    "psd_0_20":             { "mse": 0.1391, "mape": 28.1207, "1_mape": 0.7188, "r2": 0.5271 },
    "psd_0_40":             { "mse": 1.8508, "mape": 8.5272, "1_mape": 0.9147, "r2": 0.5551 },
    "psd_0_80":             { "mse": 4.7497, "mape": 3.1521, "1_mape": 0.9685, "r2": 0.1253 },
    "psd_0_105":            { "mse": 3.5379, "mape": 1.9094, "1_mape": 0.9809, "r2": 0.024 },
    "psd_0_149":            { "mse": 1.1595, "mape": 0.8483, "1_mape": 0.9915, "r2": 0.0124 }
  }
}
```

**指标含义**

| 字段 | 说明 |
| --- | --- |
| `mse` | 均方误差 |
| `mape` | 平均绝对百分比误差（%） |
| `1_mape` | `1 - mape/100`，即精度百分比 |
| `r2` | 决定系数，越接近 1 越好；`< 0` 表示不如直接用均值 |

**训练流程（固定参数）**

| 步骤 | 设置 |
| --- | --- |
| 清洗 | 10 特征 + 7 目标逐列 `to_numeric(coerce)` 后 `dropna` |
| 切分 | `test_size=0.2`，`random_state=34`，所有目标共用同一切分 |
| 特征标准化 | `StandardScaler` 在训练集 fit |
| 模型 | SVR，网格搜索 `C∈{0.1, 1.0}` × `kernel∈{linear, rbf}`，5 折 CV 选 `neg_mse` 最优 |
| 目标标准化 | 每个目标单独 `StandardScaler` |

### 4.3 `POST /correlation` — 相关性分析

计算任意参数组合的 Pearson 相关系数矩阵。

**请求体**

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `dataset_id` | int | 否 | 同 `/train` |
| `params` | string[] | 否 | 英文 key 列表；不传默认全部 10 个模型特征 |

可用 key：10 个模型特征 + `particle_size` + `energy_consumption` + `psd_*` + `nozzle_31_count` / `nozzle_33_count`
（喷嘴 key 会自动解析「3.1 5个 3.3 2个」这类文本列）

```json
{
  "params": ["particle_size", "energy_consumption", "sic3203", "fi3108",
             "sic1008", "solid_content", "gun_count", "viscosity",
             "nozzle_31_count", "nozzle_33_count"]
}
```

**响应**

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "columns": ["particle_size", "energy_consumption", "sic3203"],
    "matrix": [
      [1.0,    0.099,  -0.066],
      [0.099,  1.0,    -0.341],
      [-0.066, -0.341,  1.0]
    ],
    "notes": [
      "[particle_size] ok (particle_size)",
      "[energy_consumption] ok (energy_consumption)",
      "[sic3203] ok (sic3203)"
    ]
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `columns` | 英文 key 顺序，与 `matrix` 行列一一对应 |
| `matrix` | 对称相关系数矩阵，对角线为 1，保留 4 位小数 |
| `notes` | 每个入参的解析状态（成功 / 从文本解析 / 失败原因） |

> 少于 2 个有效参数报 `need at least 2 numeric parameters`；有效行少于 3 报 `too few valid rows`。

### 4.4 `POST /optsearch` — 工艺参数寻优

基于指定模型的粒径/能耗 SVR，用粒子群算法搜索工艺参数组合。

**请求体**

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `model_id` | string | 否 | 最新模型 | 训练返回的模型 ID |
| `target_size` | float | **是** | — | 目标粒径（μm） |
| `algorithm` | string | 否 | `weighted` | `weighted` / `mopso` |
| `alpha` | float | 否 | `0.7` | 粒径权重，`[0,1]`；能耗权重为 `1-alpha` |
| `max_iter` | int | 否 | `200` | 迭代次数 |
| `num_particles` | int | 否 | `100` | 粒子数 |
| `params` | array | **是** | — | 参数配置列表，见下表 |

**`params` 元素结构**

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `name` | string | 参数英文 key |
| `locked` | bool | `true` = 固定为 `value`，不参与寻优 |
| `value` | float | 锁定值（`locked=true` 时必填） |
| `lower` | float | 寻优下界（`locked=false` 时使用） |
| `upper` | float | 寻优上界（`locked=false` 时使用） |

未出现在 `params` 中的模型特征，默认使用训练数据的实际 min/max 作为边界。
`nozzle_31_count` / `nozzle_33_count` 等展示参数不参与寻优，仅原样回显。

```json
{
  "algorithm": "weighted",
  "alpha": 0.7,
  "target_size": 75.0,
  "max_iter": 200,
  "num_particles": 100,
  "params": [
    { "name": "sic3203", "locked": false, "lower": 46.5, "upper": 47.5 },
    { "name": "sic1014", "locked": false, "lower": 45.0, "upper": 45.8 },
    { "name": "sic3204", "locked": false, "lower": 48.8, "upper": 49.3 },
    { "name": "prc3101", "locked": false, "lower": 9.5,  "upper": 11.5 },
    { "name": "fi3108",  "locked": true,  "value": 9.0 },
    { "name": "sic1008", "locked": false, "lower": 9.0,  "upper": 16.0 },
    { "name": "sic1009", "locked": false, "lower": 9.0,  "upper": 16.0 },
    { "name": "solid_content", "locked": true, "value": 38.8 },
    { "name": "gun_count",     "locked": true, "value": 8 },
    { "name": "viscosity",     "locked": true, "value": 20 },
    { "name": "nozzle_31_count", "locked": true, "value": 6 },
    { "name": "nozzle_33_count", "locked": true, "value": 2 }
  ]
}
```

**响应**（注意 `code` 为 `200`）

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "model_id": "20261113154943",
    "algorithm": "weighted",
    "alpha": 0.7,
    "target_size": 75.0,
    "optimized_parameters": [
      { "name": "sic3203", "value": 47.1234, "locked": false },
      { "name": "fi3108",  "value": 9.0,    "locked": true  },
      { "name": "nozzle_31_count", "value": 6, "locked": true }
    ],
    "predicted_particle_size_um": 74.9821,
    "predicted_energy_consumption": 133.6217,
    "pareto_solutions": null
  }
}
```

| 字段 | 说明 |
| --- | --- |
| `optimized_parameters` | 推荐参数组合，顺序同训练时的特征顺序 |
| `predicted_particle_size_um` | 该组合下的预测粒径 |
| `predicted_energy_consumption` | 该组合下的预测能耗 |
| `pareto_solutions` | 仅 `algorithm=mopso` 时返回数组，`weighted` 时为 `null` |

**`pareto_solutions` 元素结构**（仅 mopso）

```json
{
  "optimized_parameters": [47.1, 45.4, 49.2, 10.4, 9.0, 12.6, 12.4, 38.8, 8, 20],
  "particle_size_um": 75.0123,
  "energy_consumption": 132.8841,
  "size_error": 0.0123
}
```

> 注意：`optimized_parameters` 在 Pareto 解中是**纯数值数组**（与顶层对象数组格式不同），按训练特征顺序排列。

**算法说明**

| algorithm | 目标函数 | 输出 |
| --- | --- | --- |
| `weighted` | `fitness = α·归一化粒径误差 + (1-α)·归一化能耗` | 单个最优解 |
| `mopso` | 双目标 Pareto（粒径误差、能耗），拥挤度剪枝维护档案 | 前沿解集 + 单个推荐解 |

## 6. 训练产物目录结构

每次 `/train` 生成一个 `weight/<model_id>/`：

```
weight/20261113154943/
├── config.json              # 训练元信息、SVR 参数、测试指标
├── feature_columns.json     # 特征列名（顺序即 SVR 输入顺序）
├── feature_bounds.json      # 各特征原始 min/max（寻优兜底边界）
├── scaler_X.pkl             # 特征标准化
├── particle_svr.pkl         # 粒径模型
├── scaler_y.pkl             # 粒径目标标准化
├── energy_svr.pkl           # 能耗模型
├── scaler_energy.pkl        # 能耗目标标准化
├── psd_0_{20,40,80,105,149}_svr.pkl
└── scaler_psd_0_{20,40,80,105,149}.pkl
```

## 8. 已知限制

1. `/optsearch` 成功返回 `code=200`，其余接口返回 `code=0`，前端需分别判断。
2. 接口无鉴权，仅适用内网部署。
3. `/predict` 不校验入参是否落在训练数据范围内，超范围值仍会返回预测结果。
4. `/train` 每次生成新目录，无自动清理机制，`weight/` 会持续增长。
5. `weight/` 中模型按目录名（时间戳）排序取最新，`model_id` 为秒级时间戳，同秒并发训练会互相覆盖。
